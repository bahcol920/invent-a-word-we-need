# Invent a Word We Need — Showergument

This entry coins **showergument**: an argument you rehearse in the shower that you will never actually have. Everyone knows the moment — standing under the water, finally delivering the perfect comeback, winning a debate that exists only in your head and will never be spoken aloud. English has no single word for that private, steamy rehearsal, so this entry gives it one: a blend of *shower* and *argument* that is sayable, spellable, and instantly understandable on first reading.
